# TALLY CONNECT — ARCHITECTURAL TERMINOLOGY & NAMING STANDARDS

**Standardized Terminology Reference for Tally Connect**

To maintain absolute clarity across the Cloud API, Desktop Agent, Developer SDK, and Database layers, all developers and code contributors must strictly adhere to the canonical terms defined below.

---

## 1. Canonical Entities & Concepts

| Concept | Canonical Term | Forbidden / Deprecated Synonyms | Definition |
|---|---|---|---|
| **SaaS Partner** | `Developer` | `User`, `Account`, `Customer` | The external software company or engineer integrating with Tally Connect. Has email, password, and JWT token. |
| **SaaS Project** | `App` / `Application` | `Project`, `Integration`, `Client` | A distinct product created by a Developer. Owns an `api_key`, `api_secret`, and `webhook_url`. |
| **Tenant Link** | `Connection` | `Session`, `Link`, `Connector` *(except agent binary)*, `Pipeline` | An authenticated bridge between a specific SaaS customer account (`external_user_id`) and an active TallyPrime company. Identified by `connection_id`. |
| **Onboarding Code** | `Activation Code` | `Pairing Code`, `OTP`, `PIN`, `Auth Code` | A single-use, 6-character human-friendly code (format `TC-XXXX`) generated by the SaaS and entered into the Desktop Agent wizard. |
| **Windows Client** | `Agent` | `Daemon`, `Runner`, `Bot`, `Client` | The background Windows application (`TallyConnectAgent.exe`) running on the customer's PC with port 9000 access to TallyPrime. |
| **Accounting Software** | `TallyPrime` | `Tally`, `TallyERP`, `Accounting Gateway` | The desktop ERP system running locally on the customer's machine on port 9000. |
| **Data Sync Cycle** | `Sync` | `Extraction`, `Pull`, `Export`, `Job` | The process where the Agent reads permitted entities from TallyPrime, transforms them to JSON, and updates the Cloud cache. |
| **Customer Data Rule** | `Permission` | `Scope`, `Privilege`, `Flag`, `Filter` | A boolean toggle controlled by the customer defining whether an accounting entity may be synchronized and accessed (e.g. `allow_inventory`). |

## 2. Supported Accounting Entity Terminology

| Entity | Canonical API Key | Public Endpoint | Description |
|---|---|---|---|
| **Customers** | `customers` | `GET /api/v1/customers` | Parties classified under Sundry Debtors in TallyPrime. |
| **Vendors** | `vendors` | `GET /api/v1/vendors` | Parties classified under Sundry Creditors in TallyPrime. |
| **Ledgers** | `ledgers` | `GET /api/v1/ledgers` | Individual ledger accounts from Chart of Accounts. |
| **Groups** | `groups` | `GET /api/v1/groups` | Account hierarchy groups from Chart of Accounts. |
| **Cost Centers** | `cost_centers` | `GET /api/v1/cost-centers` | Cost categories and centres allocated to vouchers. |
| **Inventory Items** | `inventory` | `GET /api/v1/inventory` | Stock items with SKU, unit, HSN, closing balance. |
| **Stock Groups** | `stock_groups` | `GET /api/v1/stock-groups` | Product categories / stock group classifications. |
| **Units** | `units` | `GET /api/v1/units` | Measurement units (e.g. NOS, KGS, BOX). |
| **Godowns** | `godowns` | `GET /api/v1/godowns` | Storage warehouses and locations. |
| **Sales Orders** | `sales_orders` | `GET /api/v1/sales-orders` | Unsettled / open sales orders. |
| **Purchase Orders**| `purchase_orders`| `GET /api/v1/purchase-orders`| Unsettled / open purchase orders. |
| **Delivery Notes** | `delivery_notes` | `GET /api/v1/delivery-notes` | Goods delivery challans awaiting final sales invoicing. |
| **Receipt Notes**  | `receipt_notes`  | `GET /api/v1/receipt-notes`  | Goods inward challans awaiting purchase billing. |
| **Sales Invoices** | `sales` | `GET /api/v1/sales` | Settled sales register vouchers. |
| **Trial Balance**  | `trial_balance`  | `GET /api/v1/trial-balance`  | Current accounting period trial balance summary. |

## 3. Function & Method Naming Conventions

### DO NOT USE Vague or Overloaded Names:
- ❌ `process()`
- ❌ `handle()`
- ❌ `run()`
- ❌ `execute()`
- ❌ `doSync()`

### PREFER Specific, Intent-Revealing Names:
- ✔ `createConnectionSession({ appId, externalUserId, companyName })`
- ✔ `getConnectionStatus(connectionId)`
- ✔ `triggerImmediateSync(connectionId)`
- ✔ `fetchCustomersFromTally()`
- ✔ `normalizeTallyCustomer(rawXmlNode)`
- ✔ `uploadSyncBatch({ connectionId, entityType, records })`
- ✔ `verifyWebhookSignature(rawBody, signature, secret)`
